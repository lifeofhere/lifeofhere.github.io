    从零开始搭建GitHub博客：Jekyll + Minimal Mistakes完整指南

    January 2, 2025 2 minute read

    今天成功搭建了基于GitHub Pages的个人博客，使用Jekyll静态网站生成器和Minimal Mistakes主题。整个过程虽然遇到了一些挑战，但最终实现了理想的效果。在这里记录完整的搭建过程，希望能帮助到有同样需求的朋友。

    项目架构设计

    双仓库架构

    为了保护源代码隐私同时享受GitHub Pages的免费托管，我采用了双仓库架构：

    • 私有仓库 (blog-source)：存储Jekyll源代码、配置文件和文章原稿
    • 公开仓库 (lifeofhere.github.io)：存储构建后的静态网站文件

    这种架构的优势：

    • ✅ 源代码保持私有
    • ✅ 享受GitHub Pages免费托管
    • ✅ 自动化部署流程
    • ✅ 版本控制和协作支持

    技术栈选择

    Jekyll + Minimal Mistakes

    Jekyll 是GitHub Pages官方支持的静态网站生成器，具有以下优势：

    • 原生支持Markdown
    • 丰富的插件生态
    • 与GitHub Pages无缝集成
    • 活跃的社区支持

    Minimal Mistakes 是一个功能丰富的Jekyll主题：

    • 响应式设计
    • SEO优化
    • 多种布局选项
    • 社交媒体集成
    • 评论系统支持

    搭建过程详解

    1. 初始化Jekyll项目

    # 创建新的Jekyll站点
jekyll new blog
cd blog

# 安装依赖
bundle install

# 本地预览
bundle exec jekyll serve

    2. 配置GitHub Actions工作流

    创建 .github/workflows/pages.yml 文件，实现自动化部署：

    name: Build and Deploy to GitHub Pages

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

permissions:
  contents: read
  pages: write
  id-token: write

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
        
      - name: Setup Ruby
        uses: ruby/setup-ruby@v1
        with:
          ruby-version: '3.2'
          bundler-cache: true
          
      - name: Build site
        run: bundle exec jekyll build
        
      - name: Deploy to GitHub Pages
        uses: peaceiris/actions-gh-pages@v3
        with:
          personal_token: $
          external_repository: lifeofhere/lifeofhere.github.io
          publish_branch: main
          publish_dir: ./_site

    3. 添加Minimal Mistakes主题

    更新Gemfile

    source "https://rubygems.org"

gem "github-pages", group: :jekyll_plugins
gem "minimal-mistakes-jekyll"

group :jekyll_plugins do
  gem "jekyll-feed", "~> 0.12"
  gem "jekyll-include-cache"
end

    配置_config.yml

    # 主题配置
theme: minimal-mistakes-jekyll
remote_theme: "mmistakes/minimal-mistakes@4.24.0"

# 网站基本信息
title: "Life OF HERE"
email: "lifeofhere@163.com"
description: "技术分享与生活记录"
baseurl: ""
url: "https://lifeofhere.github.io"

# 作者信息
author:
  name: "Life OF HERE"
  avatar: "/assets/images/avatar.jpg"
  bio: "技术爱好者，终身学习者"
  location: "China"
  email: "lifeofhere@163.com"
  links:
    - label: "GitHub"
      icon: "fab fa-fw fa-github"
      url: "https://github.com/lifeofhere"

# 插件配置
plugins:
  - jekyll-paginate
  - jekyll-sitemap
  - jekyll-gist
  - jekyll-feed
  - jekyll-include-cache

# 默认布局
defaults:
  - scope:
      path: ""
      type: posts
    values:
      layout: single
      author_profile: true
      read_time: true
      comments: true
      share: true
      related: true
      show_date: true

    4. 创建页面结构

    导航配置 (_data/navigation.yml)

    main:
  - title: "首页"
    url: /
  - title: "关于"
    url: /about/
  - title: "文章分类"
    url: /categories/
  - title: "标签"
    url: /tags/
  - title: "归档"
    url: /year-archive/

    创建功能页面

    • _pages/about.md - 关于页面
    • _pages/category-archive.md - 分类页面
    • _pages/tag-archive.md - 标签页面
    • _pages/year-archive.md - 归档页面

    5. 优化首页布局

    更新 index.markdown，添加特色区域和现代化布局：

    ---
layout: home
author_profile: true
header:
  overlay_color: "#000"
  overlay_filter: "0.5"
  overlay_image: /assets/images/header-bg.jpg
  actions:
    - label: "了解更多"
      url: "/about/"
excerpt: "欢迎来到我的个人博客！这里记录着我的技术学习心得、生活感悟和思考分享。"
---

    遇到的问题与解决方案

    1. GitHub Actions部署失败

    问题：”not found deploy key or tokens” 错误

    解决方案：

    1. 创建Personal Access Token（需要repo和workflow权限）
    2. 在私有仓库中添加PERSONAL_ACCESS_TOKEN密钥
    3. 确保目标仓库存在且为公开状态

    2. 主题样式不生效

    问题：页面显示简单样式，主题特性未加载

    解决方案：

    1. 修复layout配置（将page改为single）
    2. 更新依赖：bundle update
    3. 重启Jekyll服务器

    3. 构建警告处理

    问题：Layout ‘page’ requested but does not exist

    解决方案：

    • 将所有使用layout: page的文件改为layout: single
    • 确保所有页面使用Minimal Mistakes支持的布局

    部署配置要点

    Personal Access Token设置

    1. 访问GitHub Settings → Developer settings → Personal access tokens
    2. 创建新token，选择以下权限：
      • repo (完整仓库访问权限)
      • workflow (工作流权限)
    3. 在私有仓库Settings → Secrets中添加PERSONAL_ACCESS_TOKEN

    GitHub Pages配置

    1. 在公开仓库Settings → Pages中
    2. Source选择”Deploy from a branch”
    3. Branch选择main分支
    4. 保存配置

    性能优化建议

    1. 图片优化

    • 使用WebP格式
    • 压缩图片大小
    • 添加适当的alt文本

    2. SEO优化

    • 配置sitemap.xml
    • 添加meta描述
    • 使用语义化HTML标签

    3. 加载速度优化

    • 启用GZIP压缩
    • 使用CDN加速
    • 优化CSS和JavaScript

    总结

    通过今天的实践，成功搭建了一个功能完整的GitHub博客。双仓库架构既保护了源代码隐私，又享受了GitHub Pages的便利。Minimal Mistakes主题提供了丰富的功能和优雅的设计，为后续的内容创作提供了良好的基础。

    整个过程中最重要的收获是学会了如何处理各种配置问题，以及GitHub Actions自动化部署的配置方法。这些经验对于后续的项目开发都很有价值。
